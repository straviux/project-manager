# Print server files, shipped inside the project manager repo

These are the same files as the standalone print server (see README.md
in this folder). They live here so the Project Manager app's Printing
tab can find them: in the app, choose this `print-server` folder as
the print-server folder on first use.

Do not edit the Python server here and in the standalone folder
separately — keep this copy as the one that ships with the app.
